# ProbeRequestDataset_AGH2026

A dataset of Wi-Fi Probe Request captures from **28 mobile devices**, containing **27,302 frames** across **140 PCAP files**.

## Dataset structure

Each directory (`A`–`Z`, `AA`, and `AB`) corresponds to the device with the matching ID in the table below. Each device directory contains five capture files: `1.pcap`, `2.pcap`, `3.pcap`, `4.pcap`, and `5.pcap`.

```text
ProbeRequestDataset_AGH2026/
├── README.md
├── A/
│   ├── 1.pcap
│   ├── 2.pcap
│   ├── 3.pcap
│   ├── 4.pcap
│   └── 5.pcap
├── B/
│   └── ...
├── ...
└── AB/
    └── ...
```
